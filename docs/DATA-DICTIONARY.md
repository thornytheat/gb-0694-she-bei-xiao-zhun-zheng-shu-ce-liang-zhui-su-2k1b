# 数据定义

证书有效期与量程双约束；参考标准也须在校准时有效，证书撤销向下游传播并检测环。

输入字段：cert, device, alias, parent, valid_from, valid_to, minimum, maximum, unit, revoked, measured_at, value, measure_unit, version。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

## 误差带（可选）

除必填列外，可增加误差带列。列名接受以下别名（每类至多一列）：

- 数值列：`error`、`uncertainty`、`tolerance`、`误差`、`不确定度`、`允差`
- 单位列：`error_unit`、`uncertainty_unit`、`tolerance_unit`、`误差单位`、`不确定度单位`、`允差单位`
- 一列写法：`error_band`、`band`、`误差带`，值形如 `±0.2 V`

规则：

- 误差带是半宽（±），必须带单位；单位支持 V、mV、µV，统一换算为伏特。一列写法自带单位；两列写法由单位列提供，若两列单位冲突则隔离。
- 误差带缺失、格式无效、缺单位、为负或单位冲突时，该行进入隔离存档，原因码为 `BAND` 或 `BAND_UNIT`。
- 误差带为空视为“未提供”，量程按读数单点判断，与旧行为一致。
- 只接受上述可选列；未知列或重复列按 `HEADER` 结构错误拒绝，不静默忽略。

## 量程裁决

量程为闭区间 [minimum, maximum]，读数与误差带均以伏特比较。

| 读数位置 | 误差带 | 量程状态 | 测量结论 |
|---|---|---|---|
| 区间外 | 任意 | `OUT` | 拒用（`OUT_OF_RANGE`） |
| 区间内 | 未提供 | `OK` | 可按其余条件采用 |
| 区间内 | 完整落在区间内 | `OK` | 可按其余条件采用 |
| 区间内 | 任一端越界 | `EDGE` | 待复测（`EDGE_BAND`） |

证书过期/未生效（`INVALID_WINDOW`）、撤销（`REVOKED`）、溯源中断（`MISSING_REFERENCE`、`CYCLE`、`REFERENCE_EXPIRED`、`REFERENCE_CONFLICT`）仍然直接拒用，不因误差带改变。`EDGE` 只在其余条件均可采用时才落入待复测。

每条量程证据都带 `量程依据` 文本，例如 `误差带越界：上限 9.995 + 0.01 = 10.005 V > 10 V` 或 `读数 5 V，误差带 ±0.001 V，两端均在 [0, 10] V 内`。

## 待复测与补交

- 待复测记录补交读数、误差带与测量日后重判。重判重新检查有效期（以补交测量日为准）、量程（以补交读数与误差带为准）与溯源链。
- 补交不改写原始批次载荷；裁决追加到独立存档表，原始结论保留在 `original_verdicts`，证据CSV的 M6 阶段仍导出原始结论并另附“复审”行。
- 裁决 ID 由批次、记录、读数、误差带、测量日确定性生成。同一份补交重复提交（含存档写入中断后的重试）命中同一条裁决，不新增。
- 记录仍为待复测时，可以用不同内容再次补交；一旦得出可采用或拒用，该记录的补交通道关闭，后续提交返回 422 `NOT_PENDING`，防止已归档的结论被反复改写。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

校准电压量程闭区间[min,max]，证书日期为半开[valid_from,valid_to)。父证书需在子证书生效日有效；撤销按追溯性撤销处理，所有下游测量拒用。同编号证书定义冲突会使其及下游失去证明力。样例是电压仪器，未处理非线性量程和不确定度传播；误差带按对称半宽处理，不区分置信水平与分布。
